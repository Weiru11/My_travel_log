# My Australia Travel Log

A responsive travel diary website presenting places I visited in Australia.  
Visitors can explore destinations through an interactive map and browse travel memories organised by activities, food, and scenery.

## Features

- Interactive SVG map of Australia
- Destination dropdown navigation
- Separate pages for Sydney, Melbourne, Brisbane, and Whitsunday
- Image sliders with matching descriptions
- Keyboard arrow navigation for image sliders
- Responsive design for different screen sizes
- Dynamic navigation-bar styling while scrolling

## Technologies

- HTML5
- CSS3
- JavaScript
- SVG

## Pages

- Home
- Sydney
- Melbourne
- Brisbane
- Whitsunday

- Structuring a multi-page website
- Creating responsive layouts with CSS
- Manipulating page elements with JavaScript
- Handling click, hover, scroll, and keyboard events

- Debugging front-end behaviour
